On your phone

  1. Install the Forest Network app for iOS or Android.
  2. Tap Sign in to matrix.theforestnetwork.earth.
  3. Follow the steps to create your account, and enter your registration token when asked.
  4. Along the way, you'll be asked for a verification code from a separate email titled “Your email verification code”. That code is used to verify your email address and is different from the registration token above, which is only used once when you create your account.

In your web browser (Element X)

  1. Open the Element X web client.
  2. When asked for your server, enter matrix.theforestnetwork.earth.
  3. Follow the steps to create your account, and enter your registration token when asked.
  4. Along the way, you'll be asked for a verification code from a separate email titled “Your email verification code”. That code is used to verify your email address and is different from the registration token above, which is only used once when you create your account.

Please set up and save a recovery key

It's very important. Without a recovery key, you'll lose your direct messages and message history in any private channels if you ever switch devices. Set one up as soon as you sign in, and keep it somewhere safe, like a password manager.
